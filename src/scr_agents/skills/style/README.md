# Style reviewer skills

Guidance only the style reviewer (subagent `style`) gets: which style and naming problems are worth reporting.

Listed in its task message; read with `skill_read`.

One folder per skill: `src/scr_agents/skills/style/<name>/SKILL.md` (format in `src/scr_agents/skills/README.md`). Switch skills on or off in the console (Configure -> Skills).
