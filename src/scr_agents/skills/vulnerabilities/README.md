# Security reviewer skills

Guidance only the security reviewer (subagent `vulnerabilities`) gets: sources and sinks, trust boundaries, how to report a vulnerability.

Listed in its task message; read with `skill_read`.

One folder per skill: `src/scr_agents/skills/vulnerabilities/<name>/SKILL.md` (format in `src/scr_agents/skills/README.md`). Switch skills on or off in the console (Configure -> Skills).
