# Bug reviewer skills

Guidance only the bug reviewer (subagent `bugs`) gets: logic errors, edge cases, error handling, resources, concurrency.

Listed in its task message; read with `skill_read`.

One folder per skill: `src/scr_agents/skills/bugs/<name>/SKILL.md` (format in `src/scr_agents/skills/README.md`). Switch skills on or off in the console (Configure -> Skills).
