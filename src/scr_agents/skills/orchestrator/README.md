# Orchestrator skills

Guidance only the OpenFlow orchestrator gets (`review.orchestrator: openflow`): which reviewers to run on what, how to spend the validation budget, when a finding may be dropped.

Listed by `skill_list`; read with `skill_read`. The deterministic flow has no orchestrator model and does not use them.

One folder per skill: `src/scr_agents/skills/orchestrator/<name>/SKILL.md` (format in `src/scr_agents/skills/README.md`). Switch skills on or off in the console (Configure -> Skills).
