# Validator skills

Guidance only the validator gets: how to build a proof, what counts as evidence, how to choose a verdict.

Listed in each finding's task message; read with `skill_read`.

One folder per skill: `src/scr_agents/skills/validator/<name>/SKILL.md` (format in `src/scr_agents/skills/README.md`). Switch skills on or off in the console (Configure -> Skills).
