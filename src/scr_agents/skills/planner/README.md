# Planner skills

How to plan a review: choosing focus files, writing hypotheses, what to tell the reviewers.

The planner has no tools, so the full text of the skills in this folder goes into its prompt (up to about 6,000 characters in total).

One folder per skill: `src/scr_agents/skills/planner/<name>/SKILL.md` (format in `src/scr_agents/skills/README.md`). Switch skills on or off in the console (Configure -> Skills).
