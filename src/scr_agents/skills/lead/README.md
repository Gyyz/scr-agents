# Lead agent skills

Guidance for the chat lead agent: when to start a review, how to explain findings to the person asking.

Listed by its `skill_list` tool and read with `skill_read`.

One folder per skill: `src/scr_agents/skills/lead/<name>/SKILL.md` (format in `src/scr_agents/skills/README.md`). Switch skills on or off in the console (Configure -> Skills).
